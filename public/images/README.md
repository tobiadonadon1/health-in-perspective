# Interface artwork

`human-portrait.png` and `digestive-anatomy.png` were generated for this interface on 2026-10-22 from the user's visual references. They are illustrative artwork, not photographs or scans of an app user and not clinical measurements.

The portrait and `vitruvian-man.png` are 2D illustrations. The Vitruvian option replaces the old generic 3D bust. Its artwork was generated specifically for the Xeyo palette from the user’s Vitruvian Man reference.

Preserve image aspect ratios. The digestive card uses `object-fit: contain`; do not recreate it by stretching a crop of the original dashboard screenshot.
