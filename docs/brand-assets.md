- Original supplied artwork: `assets/xeyo-orb-source.png`

Processing used the built-in image generation tool in edit mode, with the supplied image as the only reference and `transparent_background: true`. Background removal was requested; no new logo design was requested.

## Edit prompt

Use case: background-extraction. Input image 1 is the edit target and the user's final approved logo, not a style reference. Remove ONLY the neutral gray background and the unrelated broad ground/background orange glow. Preserve the exact orange-red orb: its existing perspective, circular silhouette, tiny woven particle/mesh texture, bright orange rim on the right and bottom, dark shaded center-left, and softly diffused upper-left edge. Do not redesign, redraw into a smooth plastic ball, add highlights, rays, words, or change its shape or color. Deliver the same orb isolated on a genuinely transparent background with the soft edge retained as partial alpha. Square canvas, centered orb occupying about 84 percent of the square, enough small transparent padding to keep its soft halo intact. Production logo cutout for use at small sizes.
